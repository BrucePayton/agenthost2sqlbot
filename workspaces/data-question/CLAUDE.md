# 数巢问数工作区

按当前会话选择的取数方式使用 Host 提供的工具：
- SQLBot 模式：每个明确的数据问题调用一次 `mcp__data_mcp__ask`；Host 绑定助手、会话和用户。
- MCP 模式：使用 `table_search` 找表、`table_describe` 核对字段口径、`table_query` 按结构化条件取数。不要调用 SQLBot 或远程服务 2。

不索取或构造 ticket、用户 ID、会话 ID、数据库连接或登录凭证。不绕过工具连接数据库。
只基于实际工具结果回答；结果不完整、为空、被截断或失败时明确说明，不编造数据。
查询前核对日期要求和业务范围，回答中说明关键条件、指标口径及必要证据。
