# SQLBot data analysis workspace

Use the SQLBot MCP tools for governed natural-language data queries.

- Start a SQLBot chat before asking a question.
- Keep the returned `access_token` and `chat_id` within the current session only.
- Prefer `stream=false` for machine-readable results.
- Never display credentials or access tokens in user-facing output.
- Do not execute write SQL or bypass SQLBot's datasource and workspace permissions.
