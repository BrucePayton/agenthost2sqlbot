# 2026-09-17 订阅单一入口验收

本记录区分真实模型验收与已解释业务输入的程序回归。后者不能证明模型首次理解、参数正确率或端到端耗时已经达标。

## 测试边界

- `tests/live/test_subscription_natural_language.py` 使用四个会话的原始中文请求，经过实际 ASGI Host、当前配置模型及真实浏览器中的 Davinci Controller、Store、引用转换和完成检查。
- 不注入模型回复、`configurationIntent` 或预置完成状态。公开工具由实际 Host 注册；页面只执行实际下发的原生操作。
- 上游仪表盘、数据集、字段、群及服务端配置校验使用测试资源。浏览器禁止外部网络；禁止业务数据查询、发送预览、保存和消息发送。
- 通知用例从已选中的“数据中心-组织空间”进入，验证准确群选择和内容；本测试不宣称覆盖跨空间导航。
- 预警资源保留额外区域筛选及独立历史查询，避免把多查询来源简化为单查询来通过测试。
- `tests/live/test_subscription_symbolic_native.py` 直接提交已解释的业务请求，验证真实发现、编译、原生操作、回读和完成。该文件不调用模型，和前述自然语言验收分开统计。

## 真实自然语言验收结果

2026-09-17 使用配置模型 `deepseek-v4-pro-0813`，四例在独立进程、数据库、浏览器中并发执行，每例总预算 75 秒。

| 案例 | 总耗时 | Host 轮数 | 结果 |
| --- | ---: | ---: | --- |
| 仪表盘截图、AI 解读和跳转 | 68.694 秒 | 1 | `SUBSCRIPTION_NO_PROGRESS`，首个模型内容未返回 |
| 昨日订单四列数据表 | 68.752 秒 | 1 | `SUBSCRIPTION_NO_PROGRESS`，首个模型内容未返回 |
| 指定空间、群和格式的固定通知 | 69.011 秒 | 1 | `SUBSCRIPTION_NO_PROGRESS`，首个模型内容未返回 |
| 昨日成交量与日环比预警 | 68.894 秒 | 1 | `SUBSCRIPTION_NO_PROGRESS`，首个模型内容未返回 |

四例均有 SDK 初始化事件，但 `query_to_first_model_content_ms=null`，页面工具调用为 0，原生 Store 最终仍为 `idle`。模型调用次数没有收到服务端用量回执，保持 `null`，不记为 0。配置入口的模型理解和执行未能被验证。

相同环境的短连接探测返回 `ConnectTimeout`；本机保存的另一入口返回 HTTP 502。证据支持模型入口连接受阻。没有切换到另一模型，也没有用构造 JSON 的成功结果替代这四例。关闭 thinking 的实际服务行为因此仍待验证。

## 原生程序回归

四个单一业务请求已通过实际浏览器回归（4 passed，6.95 秒）：

- 固定通知：准确 BI 测试群、每月 1 号 09:00、原生 @所有人、斜体和原链接，未查数据。
- 仪表盘：09:00/18:00，截图、真实 AI 组件、跳转按钮引用同一来源。
- 定时数据：每周一 14:00、昨日筛选、准确四字段及表格列。
- 条件预警：引用真实监测查询，原值与日环比各自绑定；保留源区域筛选及独立历史查询；完成后未保存。

另外验证了“同一数据集的昨日/上月两个查询及表格保持独立”和“调整时间保留原生人工标题”。六项合并最终运行 **6 passed，10.94 秒**。两个原生资源夹具检查另计 **2 passed，3.07 秒**。这些是程序及原生页面回归耗时，不是模型端到端业务耗时。

重跑真实模型验收需设置 `RUN_LIVE_SUBSCRIPTION_SCENARIOS=1`，通过各自独立的 pytest 进程选择四个参数用例；`SUBSCRIPTION_LIVE_REPORT_DIR` 指定报告目录，`SUBSCRIPTION_LIVE_TOTAL_SECONDS` 控制单例预算。凭据从现有环境或已有 Claude 配置读取，不写入仓库。
