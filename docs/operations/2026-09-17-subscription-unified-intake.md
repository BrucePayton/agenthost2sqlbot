# 订阅配置统一入口实施记录

## 执行流程与分工

新会话的订阅配置只向模型提供 `subscription.configure`。模型先在聊天正文回显需求，在同轮提交已经确定的业务内容。输入包含归属、资源与字段声明、原生操作语义、业务问题及答案；尚未取得的引用使用类型化逻辑键，已明确的筛选、比较、接收人和内容不再转写成文字待办。

Host 根据现有原生操作契约生成模型参数结构，执行原子校验后承接请求。程序负责独立配置先行、准确资源查找、字段证据复用、逻辑引用解析、依赖排序、默认标题与名称、原生批次和版本管理。原生页面工具仍是实际写入与回读的唯一通道。`subscription.configure` 是 Host 入口，不是新增的浏览器命令。

每次写入前后沿用 `subscription.progress` 事件，在聊天正文显示正在配置及真实结果；页面切换沿用已有 Bridge。只填写标题不会再宣称正文已经配置。同名来源的程序问题与 A/B 答案共用映射，无需额外模型轮次。

原生完成回执与业务要求共同决定完成状态。最终总结来自当前配置；用户在“命名并保存”页面手动点击“发送预览”，核对后保存。自动预览、发送、保存及启用均未开放。

## 主要代码

- `app/runtime/subscription_protocol.py`：从原生契约派生业务输入，精确返回参数错误路径；保留七类内容、动态接收人与原生查询能力。
- `app/runtime/subscription_compiler.py`：解析资源/字段/查询/输出逻辑键；维护增量请求、证据和命令回执。
- `app/runtime/subscription_executor.py`：复用原有权限、归属、任务身份、原生调度、版本恢复与完成核对。
- `app/runtime/claude.py`：模型入口注册、实际原生调用延迟执行、程序续跑、业务问题展示、重复无效参数停止。
- `app/runtime/subscription_model_context.py`：模型只读取一份业务表达及已确认事实，避免并列旧绑定和新请求。
- 订阅 Skill、工作区 CLAUDE 与 locate-data：按上述职责分工收敛；技术参考保留历史维护用途。

原生共享契约文件未改变。模型结构的引用联合类型复用定义以满足工具大小限制；原生写入仍经过原有严格校验。业务请求的累计操作不受单次原生 32 项限制，程序分批执行。

## 历史会话与发布边界

会话中的 Skill 为冻结快照。带有旧执行状态或旧订阅 Skill 描述的会话继续使用原有入口，避免将未完成要求静默迁移成不完整的新请求。新协议任务固定使用版本 2。不能仅更新 Host 代码就假定历史会话中的 Skill 已更新。

本次实施未发布 Skill、部署环境或重启已有服务；Git 提交与推送按用户后续授权执行。验证新路径时需使用包含新版订阅 Skill 的新会话。外部服务可用性、实际登录态及 UAT 发布后的行为必须另行核对。

## 验证口径

验证分为三个层次，不能相互替代：

1. 协议、编译与运行时回归：检验已解释业务输入、引用、错误、续跑及完成状态。
2. 真实原生控制器与 Store：浏览器中使用生产代码，隔离资源元数据，校验实际配置及未保存状态；不等同于自然语言识别成功。
3. 原始自然语言 → 真实模型 → Host → 原生控制器：四个用户案例独立执行并记录首写耗时、完成耗时、模型轮次、原生事件与最终配置。提供方连接错误必须记为未通过，不得替换成预制模型输入后宣称通过。

跨仓库启动检查已执行，包括生成文件、实际 bundle、Host bootstrap/embed、工具目录、Bridge 及双 Origin iframe。原生契约生成和 bundle 重建没有产生内容变更。

本轮真实模型服务探测出现连接失败和 HTTP 502；因此尚不能据单元或原生测试宣布自然语言成功率与耗时改善已验收。

四个真实模型案例分别耗时 68.694、68.752、69.011、68.894 秒（仪表盘、数据、通知、指标预警），均返回 `SUBSCRIPTION_NO_PROGRESS`。`query_to_first_model_content_ms` 为 null，模型轮次未知，不能写成“模型轮次为 0”。实际工具调用、数据预览及持久化规则均为 0。这批结果只能证明未获得模型响应，不能作为四种业务配置成功或失败的结论。

原始模型验收报告位于 `/private/tmp/subscription-entry-nl-7psx7epk/<scenario>/subscription-live-evaluation.json`，场景名为 `dashboard`、`data`、`notification`、`widget_alert`。模型连通后使用 `tests/live/test_subscription_natural_language.py` 重新验收，不能用原生编译测试的耗时替代。

原生测试期间发现并修复了真实兼容问题：监测来源的旧回读没有 `sourceBinding.queryRef`，需要从该来源的原生条件绑定确定监测查询；额外查询和区域筛选必须保留。另补回归覆盖手工修改后只改时间/标题不回滚、字段分页、换源关联引用、删除查询、连续正文修改与上传图片引用。
